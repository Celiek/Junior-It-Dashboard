O projekcie Junior IT Analytics

Aplikacja monitoruje i analizuje rynek ogłoszeń pracy dla początkujących programistów i specjalistów IT w Polsce. Jej celem jest dostarczanie przejrzystych danych dotyczących szybko zmieniających się realiów rynkowych: stawek, najczęściej wymaganych umiejętności, rozłożenia ofert w dużych aglomeracjach oraz pokazania którzy pracodawcy najczęściej zatrudniają. Nad projektem pracuje jeden programista w ramach nauki, jeśli zauważysz jakieś błędy / sugestie napisz do mnie na discordze : Junior IT Analytics

Zbieranie i Przetwarzanie Danych

Dane są automatycznie gromadzone przez dedykowany web scraper, a następnie trafiają do relacyjnej bazy danych. Przed prezentacją na wykresach przechodzą proces normalizacji typów umów, widełek płacowych oraz tagów technologii wymaganych w ofertach.

  • Cykliczna ekstrakcja ogłoszeń z czołowych portali pracy
  • Czyszczenie anomalii i standaryzacja stawek do kwot miesięcznych
  • Grupowanie mniejszych miejscowości w zbiorcze segmenty

Użyte Technologie

Warstwa frontendowa została zbudowana w oparciu o :

Angular (Standalone) TypeScript Chart.js & ng2-charts Tailwind CSS REST API - Java Spring, baza danych PostgreSQL
